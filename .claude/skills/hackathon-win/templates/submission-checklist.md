# Pre-submit checklist

Run against the **live submission page**, 2+ hours before deadline. Submit early; most platforms allow edits until close.

## Blockers
- [ ] Demo video is public, plays start to finish, embedded on the page (not just linked)
- [ ] Video is under the hackathon's stated length cap
- [ ] Live link opens in a **logged-out incognito window** and works
- [ ] Repo is public and the link resolves
- [ ] Repo has a LICENSE file (if the README claims a license, the file must exist)
- [ ] Every eligible prize track / category is selected — free points, routinely missed
- [ ] All required fields on the submission form are filled
- [ ] Team members added, if any

## Scored content
- [ ] First two sentences state a specific problem, in plain language
- [ ] "What it does" describes what the demo actually shows — no claims beyond it
- [ ] Every image has a caption; captions aren't truncated by the platform's limit
- [ ] Images show the product, not the code editor
- [ ] Tags/tech list contains only what's genuinely used — no padding
- [ ] Attribution section: data sources, licenses, media, fonts, anything not original
- [ ] One honest limitation stated
- [ ] Elevator pitch fits the character limit without cutting mid-word

## Live-site sanity
- [ ] Loads in under ~3 seconds
- [ ] No console errors on first load
- [ ] First screen explains itself without narration
- [ ] Works on a phone-width viewport
- [ ] Any shared/deep link a judge might click opens in the right state
- [ ] Real data is actually flowing, right now

## Final
- [ ] Read the whole page out loud once
- [ ] Watch the video once more, all the way through
- [ ] Click every link on the page
- [ ] Submitted, with time to spare
